# Programming 1 - Session 3

This folder contains my solutions for the Cafe Lambda exercise.

Finished parts:

- c1_lookup.py: finds price, name and category from the menu
- c2_total.py: calculates a three-item order with VAT
- c3_discount.py: applies customer, happy-hour and big-spender discounts
- c4_change.py: calculates cash change without loops
- c5_receipt.py: prints one complete receipt
- c6_explain.py: explains the price calculation step by step

Pair work:

- Challenge 1-4: completed as pair-programming practice in class
- Challenge 5-6: completed individually

Notes:

- I used functions and conditionals only.
- The change task was the most repetitive part because loops were not allowed.
- The explanation task helped me see the order of the calculation more clearly.
